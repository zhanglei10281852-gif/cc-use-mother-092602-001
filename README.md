# 科学计算任务运营服务

这是一个面向科研平台、实验室和计算中心的 Python 后端，使用 FastAPI 与 SQLite 管理参数模板、计算任务提交、优先级排队、工作者领取、取消、失败重试、租约恢复、用户配额、结果版本和管理员人工干预记录。服务同时保留用户、角色、会话和审计等基础能力，所有运行数据都在单个本地数据库文件中，不需要另行部署数据库、缓存、消息队列或浏览器界面。

卫星载荷场景由 `app/payload` 模块提供：值班工程师配置有限散热窗口（起止时间、能量预算、功耗上限），提交带预计耗时、功耗和优先级的计算请求；只有在窗口激活且温度预算允许时才能领取任务，窗口即将结束时一键安全暂停全部在运行任务，跨窗口恢复时保留原始优先级与剩余工作量，完成后签发回执，全程留有审计记录。

## 已有能力

- 参数模板：保存参数类型、必填项、数值范围、默认值、最大运行时间和最大尝试次数。
- 任务提交：根据模板校验参数，使用用户与幂等键避免重复创建，并保存项目、提交人和输入摘要。
- 排队领取：按优先级和进入队列的顺序分配任务，工作者可声明算法能力并获得有期限的租约。
- 执行回执：工作者可以续租、提交结果或报告失败；可重试错误使用确定的退避时间重新排队。
- 失败恢复：租约过期后可由恢复入口将任务重新排队，达到最大尝试次数的任务转为失败。
- 配额控制：可保存用户、角色或项目的排队数、运行数和每日提交上限；当前提交路径执行用户配额。
- 结果版本：每次成功回执保存不可变结果、指标摘要和内容摘要，任务指向当前结果版本。
- 人工干预：取消、人工重试、优先级调整和批量操作均保留操作者、原因、前后状态和批次标识。
- 登录与角色：基础管理模块提供管理员初始化、用户、角色、会话和细粒度权限。

## 卫星载荷热窗口调度

- 热窗口配置：`POST /api/payload/windows` 保存窗口起止时间、能量预算（焦耳）和单任务功耗上限（瓦特），名称唯一且不允许时间重叠；`GET /api/payload/windows` 返回按当前时间推导的窗口状态（scheduled/active/closed）与剩余能量。
- 任务提交：`POST /api/payload/tasks` 接收预计耗时（秒）、功耗（瓦特）和优先级（0-100）。同一提交人重复提交同一幂等键返回原任务并标记 `idempotent_replay`；同一幂等键对应不同请求参数时返回 409。
- 排队与领取：`POST /api/payload/tasks/claim` 只在窗口激活、能量预算剩余且任务功耗不超过窗口上限时，按优先级与提交顺序发放任务；暂停中的任务以剩余工作量参与同一优先级队列。
- 暂停恢复：`POST /api/payload/windows/{id}/pause` 将窗口内全部在运行任务安全暂停，按窗口结束时间钳制计费时长，累计运行秒数与能耗写回任务与窗口，原始优先级和剩余工作量完整保留，下一窗口领取时自动恢复。
- 完成回执：`POST /api/payload/tasks/{id}/complete` 结算本次运行时长与能耗，签发包含总运行秒数、总能耗和跨窗口次数的回执；重复完成返回同一回执。
- 审计查询：`GET /api/payload/audit` 按任务、窗口或事件类型查询提交、领取、暂停、恢复、完成和窗口事件。
- 计划复现：`GET /api/payload/plan?at=<ISO时间>` 或 `python -m app.cli payload-plan --at <ISO时间>` 按相同规则推演队列在后续窗口中的分段执行、能耗与完成时间；能耗统一按 `焦耳 = 瓦特 × 秒` 计算并保留 6 位小数，相同数据与相同时刻的输出完全一致。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/compute-operations.db`。可以复制 `.env.example` 并通过 `TOWNSHIP_DATABASE_PATH` 指定其他本地路径。

## 数据库初始化与检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8432
```

健康检查：

```bash
curl -sS http://127.0.0.1:8432/api/system/health
```

计算任务摘要位于 `/api/compute/summary`，模板、配额、提交、领取、回执和人工操作接口统一使用 `/api/compute` 前缀；载荷热窗口调度接口统一使用 `/api/payload` 前缀，摘要位于 `/api/payload/summary`。

## 测试

```bash
python -m pytest
```

## API 冒烟

```bash
python -m app.cli smoke
python -m app.cli compute-demo
python -m app.cli payload-demo
python -m app.cli payload-plan --at 2026-09-27T01:00:00+00:00
```

`smoke` 在进程内检查根路径和健康接口，`compute-demo` 会创建示例参数模板、提交一个计算任务并让匹配能力的工作者领取，用于快速确认核心运营链路。`payload-demo` 演示开窗、幂等提交、领取、安全暂停、恢复领取和完成回执的完整链路；`payload-plan` 按指定时刻输出可复现的调度计划。

## 目录结构

```text
app/
  compute/         计算模板、配额、任务、结果版本和人工干预
  payload/         卫星载荷热窗口、任务排队领取、暂停恢复、回执与审计
  api/             用户、角色、认证、审计和系统管理接口
  core/            时钟、安全、异常和分页能力
  repositories/    通用 SQLite 查询
  seismic/         既有地震计算示例领域
  services/        身份、审计和通用后台任务服务
  cli.py           初始化、检查、冒烟和计划推演入口
  database.py      SQLite 连接、事务、表结构与基础权限
tests/             核心、计算运营、载荷调度和身份回归测试
tools/             本地维护脚本
```

## 数据一致性

SQLite 连接启用外键、WAL、busy timeout 和同步写入策略。提交、领取、回执和人工干预使用即时事务；任务领取通过条件更新避免同一条排队记录被重复领取。服务保存 UTC 时间字符串，测试可以注入固定时钟验证退避、租约到期和跨日配额。会话令牌只保存摘要，审计与人工干预记录不会写入明文密码或令牌。载荷任务的暂停与完成在同一个即时事务内结算运行秒数、能耗和窗口预算，计费时长不会越过窗口结束时间，暂停事件与任务状态同时落库，不会出现无记录丢失的任务。
